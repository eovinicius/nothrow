# Getting help

- **Usage questions and ideas:** start a thread in [Discussions](https://github.com/eovinicius/nothrow/discussions).
- **Bugs:** open an [issue](https://github.com/eovinicius/nothrow/issues/new/choose) with the bug report template.
- **Security vulnerabilities:** report them privately, as described in [SECURITY.md](SECURITY.md).

The [README](README.md) covers the whole API, including common pitfalls.

NoThrow is maintained by volunteers in their spare time, so there is no guaranteed response time.
