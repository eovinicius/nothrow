# Security Policy

## Supported versions

NoThrow is pre-1.0. Security fixes are released only for the **latest published version** on
[nuget.org](https://www.nuget.org/packages/NoThrow); upgrade to it to receive them.

## Reporting a vulnerability

**Do not open a public issue, discussion, or pull request for a security problem.**

Report it privately through GitHub's
[private vulnerability reporting](https://github.com/eovinicius/nothrow/security/advisories/new)
(the **Report a vulnerability** button on the repository's *Security* tab). Please include:

- the affected version(s);
- a description of the issue and its impact;
- steps or a minimal snippet to reproduce it.

You can expect an acknowledgement within a few days. Once the issue is confirmed, a fix is prepared in a private
advisory, released as a new version, and the advisory is published with credit to you, unless you prefer to stay
anonymous.
